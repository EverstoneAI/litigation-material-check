# 诉讼材料自检（Litigation Material Self-Check）

给要打官司、又没请律师的你：起诉状/答辩状写完，先自查一遍**材料齐不齐、话说得规范不规范**。

核心规矩只有一条：**每一条事实都要挂上证据编号**——挂不上的就是"无据陈述"，法官不会采信。

单文件网页 · 零依赖 · 完全离线 · **你粘贴的文字不上传**

---

## 快速开始

- **在线用**：打开在线版：<https://everstoneai.github.io/litigation-material-check/> ，点开即用。
- **本地用**：下载 `index.html`，双击用浏览器（Chrome / Edge 等 2018 年后的版本）打开。无需安装、无后端、不联网。

使用流程：选纠纷类型 → 左侧登记证据目录 → 把起诉状/答辩状整段粘进来 → 点「开始检查」→ 右侧出报告 → 「复制检查报告」带走。

## 它检查什么

1. **材料清单**：六类纠纷（民间借贷 / 劳动争议 / 房屋租赁 / 消费纠纷 / 交通事故 / 婚姻家庭）各一份待办清单——备什么、备几份、去哪找，可勾选计数；通用项（起诉状份数、身份证明、被告信息、证据目录、送达地址确认书）每类都带，劳动争议自带"先仲裁"流程提醒。
2. **表述自检（四类）**：
   - **无据陈述**（核心机制）：事实句句尾没挂「证据N」编号的逐句标出，并按内容提示去哪找证据（转账记录→银行流水、事故→交警认定书……共 12 类指引）；
   - **套话无信息**：命中"性质极其恶劣"等套话后，教你换成"谁＋时间＋行为＋损失金额"；
   - **情绪化表述**：标出情绪词，提示删掉只留事实和后果；
   - **缺项**：当事人信息不全、缺诉讼请求、缺事实与理由、缺证据目录，逐项给补法。
3. **证据交叉核对**：正文引用了目录里不存在的编号（悬空）、目录里的证据正文没引用（未使用），都会被抓出来。中文数字引用（"证据一"）也认。
4. **待补清单**：以上全部发现合并成一份编号清单，每条写清"补什么、去哪找"，可一键复制全文报告。

## 附带的四块参考信息

- **证据收集指南**：按纠纷类型列出要收集的资料，每条附「没有也不慌」的替代办法（如押金没收条→查支付流水；病历丢了→医院病案室复印）。
- **公开案例四条经验**：协议就是证据、对方身份先核实、主张的权利要写对名字、原始载体别删——只谈材料，不谈输赢。
- **律师与法律帮助**：法律援助（经济困难可免费）、工会/消协/妇联/残联、怎么核实律师资质防"假律师"、以及自己打官司完全可以。
- **投诉建议渠道 + AI 提示词**：12345 与人民建议箱怎么写（五要素），附两段可直接复制的 AI 起草提示词。

## 它不做什么（红线）

页面横幅、页脚、检查报告末尾都有这句话：

> 本工具只做材料完整性与表述规范性检查，不替代律师，不构成法律意见。具体法律问题请咨询律师或拨打公共法律服务热线 12348。

- 不给法律意见、不判输赢、不预测结果；不做"该不该起诉"的判断
- 没有法条检索、没有判例引用、没有诉状代写——那些属于法律服务，是本项目的边界
- 不推荐、不评价任何律师或机构

## 隐私与安全

- 所有检查在你本机浏览器完成，文字**不上传、不联网、无统计埋点**
- 代码就 `index.html` 一个文件，无构建、无依赖，全部逻辑可直接审阅

## 自测

在地址后加 `?selftest=1`：工具会自动填入一段埋了问题的探针材料并跑一遍，页面顶部黑条显示各类命中数（全 0 才说明坏了）。实测记录见 [docs/selftest.md](docs/selftest.md)。

## 已知边界

- "无据陈述"是启发式（数字＋事实动词＋证据编号），不是语义理解：不含数字也不含事实动词的定性事实句可能漏标
- 材料清单勾选只在当页生效，刷新清零（刻意保持零依赖；欢迎 PR 加 localStorage）
- 证据编号支持一~九十九的中文数字，更大的请用阿拉伯数字
- 未做打印样式精调（浏览器直接打印可用）
