# 自测记录（selftest）

本工具内置自测开关：地址后加 `?selftest=1`，会自动填入一段埋了四类问题的探针材料并跑一遍检查，页面顶部黑条显示各类命中数——全 0 才说明检测逻辑或词库坏了。

## 一、静态扫描（2026-09-18，卡 7 首版实测）

- 双花括号 / @@ / TODO / xxx / 示例占位 / http(s):// / fetch( / XMLHttpRequest：全 0
- 禁用词「包赢 / 必胜 / 一定能 / 稳赢 / 必赢」：0（"赢""胜"两字全篇未出现）
- 12348 免责声明：恰 3 处（页面横幅 / 页脚 / 复制报告末尾）
- UTF-8 无乱码；外部依赖 0（无 CDN / 外链 / fetch / XHR）
